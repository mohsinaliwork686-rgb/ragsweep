# Procurement

Anything bought with company money goes through a purchase request, including software
subscriptions and hardware.

A purchase request names the vendor, the amount, and the reason. It is then approved
according to the standard thresholds, which are set out in the approvals policy.

New vendors must pass a security review before the first purchase. The review takes about
two weeks, so it should be started early.

Software subscriptions that renew automatically must be registered in the subscription
register, so renewals are not paid for tools nobody uses any more.

Staff must never buy something personally and claim it back as an expense in order to
avoid a purchase request.
